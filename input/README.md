# Input Folder

Place photos or recorded videos here, then run:

```powershell
.\.venv\Scripts\python.exe src\main.py --process-media
```

On Windows, you can also double-click `Run Media Export.cmd` in the project
folder.

Annotated copies will be created in the `output` folder.

Supported photos: `.bmp`, `.jpeg`, `.jpg`, `.png`, `.webp`  
Supported videos: `.avi`, `.m4v`, `.mkv`, `.mov`, `.mp4`
